## TU FOTO

Pon tu foto en:
assets/profile.jpg

Idealmente:
- JPG o PNG
- Foto vertical o cuadrada
- Buena iluminación
- Fondo limpio

Si no existe profile.jpg, la página muestra automáticamente "TN".

## LOGOS

PostgreSQL, MySQL, Python, Java y Docker usan Devicon desde CDN.
El logo de pgAdmin se representa con CSS para evitar que aparezca una imagen rota.

Si quieres que todo funcione completamente offline, después podemos descargar los SVG de los logos y dejarlos dentro de assets/logos/.
